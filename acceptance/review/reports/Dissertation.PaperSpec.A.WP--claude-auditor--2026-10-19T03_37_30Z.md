# Reading: def PaperSpec.A.WP (WP(lambda))

Paper: "Call the system (4.1) well posed at lambda — WP(lambda) — if it has a unique solution in HH
for EVERY such forcing q", the forcings being square-integrable with q^b, q^sigma, q^f progressive,
q^h predictable (P (x) E-measurable, square-integrable for dP x dt x nu), q^g_T in L^2(F_T).
A faithful Lean definition: WP(lambda) := for every forcing q in that class, there exists a
solution of (4.1) at lambda with forcing q in HH (ForcedSolution), and any two such solutions are
equal modulo the HH identification (X, Y indistinguishable; Z equal dt x dP-a.e.; U equal
dt x dP x nu-a.e. — equivalently HH-distance 0).
* Uniqueness must be in that equivalence sense: literal equality of Lean functions would be
  false for every system (null-set modifications) and so would make WP unsatisfiable (Lemma 4.2
  then false, and every hypothesis WP(lambda0) of Lemma 4.4 vacuous).
* The forcing class must be exactly the paper's (not a smaller class, which would weaken WP; not a
  larger one with non-predictable q^h, which would strengthen it beyond the paper).
* The system (coefficients, xi0, basis, T) is fixed; lambda in [0,1].
