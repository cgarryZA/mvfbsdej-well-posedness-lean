# Reading: ex_brownian (main clause), Example 5.2 Brownian reduction

Paper: remove the Poisson channel from the basis (filtration generated by W and F_0, Brownian
PRP), delete the U-coordinate (H_B = R^n x R^m x R^{m x d}); "the assumptions reduce to
W_2-Lipschitz joint-law dependence of (X,Y,Z) under G-monotonicity" (BYZ (A1) with rectangular
full-rank G); with no jump channel the U-dissipativity constraint of Remark 2.10 is vacuous, so
both rank branches of Ass. 2.5 are available. The example's point (§5 preamble: "recover the
Brownian [BYZ] subclass as special case") is that the main results (Thm 3.5 well-posedness, with
uniqueness Thm 3.3 and stability Thm 3.1) apply to the Brownian MV-FBSDE.

The "main" clause, faithful form:
- Setting: a Brownian basis: probability space, d-dim BM W, independent initial sigma-field
  F_0, filtration = usual augmentation of sigma(W) v F_0; horizon T > 0, dimensions n, m, d >= 1.
  (Representation via the jump framework with nu = 0 -- E a point, L^2(nu) = {0} -- is an
  acceptable encoding: then N = 0 a.s., the filtration is generated by W, F_0, the U-coordinate
  is the zero element and the Poisson integrals vanish; NOT acceptable: h = 0 on a basis with
  nontrivial nu, which the paper explicitly says is not a reduction.)
- Coefficients b, sigma, f on [0,T] x H_B x P_2(H_B), g on R^n x P_2(R^n), Borel; W_2 on
  P_2(H_B) for the Euclidean/Frobenius norm.
- Hypotheses = reduced Ass. 2.2-2.5: xi0 in L^2(F_0); origin values in L^2(0,T); diagonal
  Lipschitz |db| + |dsigma|_F + |df| <= L(|dX| + |dY| + |dZ|_F + W_2(mu, mu')) a.s. for a.e. t and
  all diagonal inputs, terminal Lipschitz; G in R^{m x n} full rank; terminal monotonicity
  E<dg, G dX_T> >= alpha E|G dX_T|^2; interior E[<db, G^T dY> + <dsigma, G^T dZ>_F + <-df, G dX>]
  <= -beta1 E[|G^T dY|^2 + |G^T dZ|_F^2] - beta2 E|G dX|^2; constants alpha, beta1, beta2 >= 0,
  alpha + beta1 > 0, beta1 + beta2 > 0, beta1 > 0 if m < n, alpha, beta2 > 0 if m > n.
- Conclusion: the Brownian MV-FBSDE X_t = xi0 + int b + int sigma dW,
  Y_t = g(X_T, Law X_T) + int_t^T f - int_t^T Z dW (laws mu_t = Law(X_t, Y_t, Z_t)) has a solution
  in S^2 x S^2 x H^2_W, unique (Thm 3.3 form), and (optionally) the stability estimate of Thm 3.1
  with constant depending only on T, L, ||G||, c_G, alpha, beta1, beta2, c_BDG.
- Alternatively, a clause expressing "the assumptions reduce": the system embedded with nu = 0
  satisfies the paper's Ass. 2.2-2.5 iff the reduced Brownian assumptions hold -- combined with
  the main theorems this gives the same content. A statement that only shows the reduced
  assumptions imply the jump-form assumptions without any well-posedness conclusion would be
  narrower than "recover the Brownian subclass".
- No hypothesis beyond the reduced assumptions (in particular no U-dissipativity, no extra
  smallness); non-vacuity witness: a Brownian system meeting the hypotheses (e.g. Ex 5.1(i)
  without jumps).

Against my reading:
- Setting "remove the Poisson channel": encoded as nu = 0 in the general framework, with (a)
  proving that the resulting filtration is the Brownian one (not h = 0 on a Brownian-Poisson
  basis, which the paper rules out). Acceptable encoding, as I anticipated.
- "Delete the U-coordinate": (b), H = R^n x R^m x R^{m x d} x {0}.
- "The assumptions reduce to W_2-Lipschitz joint-law dependence of (X,Y,Z) under G-monotonicity":
  not restated as an equivalence, but it follows by inspection from (b) and (c): with nu = 0 the
  h-terms, U-terms and the jump pairing of Ass. 2.3/2.5 vanish identically (L^2(0) = {0}, the
  nu-integral is 0), and W_2 on P_2(H) is the (X,Y,Z)-law W_2; projP2 is moreover a bijection
  (liftB_projB) so coefficients on P_2(H) are coefficients on P_2(H_B). The comparison with
  BYZ (A1) is a literature remark, not formalised (fine).
- "Both rank branches available": (d), as the existence of an m < n system with beta1 > 0 and an
  additive (here necessarily trivial) jump coefficient -- exactly the case Remark 2.10 excludes
  with jumps. The m >= n branch needs no comment (it is available with jumps too).
- My reading allowed as alternative a well-posedness conclusion for the Brownian system. The
  example's text claims the reduction, not a new theorem; well-posedness of the Brownian system
  follows from the main theorems, which the Lean states for all sigma-finite nu, nu = 0
  included. So the absence of a well-posedness conclusion is not a lost case of this clause.
- Quantifiers: universal over the basis (stronger than the standing one). d >= 1 required only in
  (d), harmless.
- Non-vacuity: hypotheses are only the basis and independence; witness ex_brownian_hypotheses
  gives a probability space with a Levy driver d = 1, nu = 0 on R, G0 = bot (and xi0 = 0 in
  L^2(F_0), 1 <= m = 1 < n = 2), so the universal statement and its inner implication for (d)
  are not vacuous.
