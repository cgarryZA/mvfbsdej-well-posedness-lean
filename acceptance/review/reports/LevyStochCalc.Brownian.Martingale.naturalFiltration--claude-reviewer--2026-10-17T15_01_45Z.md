Paper notion. Section 2, line 228: "(F_t) is the usual augmentation of the one generated by W, N and an
independent initial sigma-field F_0". The raw filtration generated by a process X is the natural
filtration F^X_t = sigma(X_s : 0 <= s <= t). This unit is (presumably) the natural filtration of a
real (scalar) process, used as an ingredient of the generated/augmented filtration.

What a faithful Lean definition must be.
- For a process X : time -> Omega -> R (each X_s measurable for the ambient sigma-algebra):
  F_t = the sigma-algebra generated by {X_s : s <= t} (supremum over s <= t of comap X_s of the Borel
  sigma-algebra), as a Mathlib Filtration (monotone, each <= the ambient sigma-algebra).
- Time index: [0,oo) (R_{>=0}) or [0,T]; if the index is R, times s < 0 must not add information not
  in the paper (if the process is only meaningful for s >= 0, including s < 0 values is harmless only
  if those values are determined, e.g. by a convention).
- No null sets and no right-continuity: those belong to the augmentation (a separate unit).
- The inequality "<= ambient" requires measurability of each X_s; if the Lean definition needs that as
  a hypothesis it should take it; a junk value (e.g. bottom or the ambient) when measurability fails is
  harmless only for measurable processes, which is the paper's case.
