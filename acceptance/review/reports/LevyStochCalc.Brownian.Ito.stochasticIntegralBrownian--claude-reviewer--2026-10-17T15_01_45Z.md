Paper notion. Section 2 (lines 222-232) and system (1.1): the Ito integral int_0^t phi_s dW_s against
the d-dimensional Brownian motion W, for integrands sigma(s,Theta_s,mu_s) (R^{n x d}), Z (R^{m x d})
that are progressively measurable/predictable and square-integrable,
E int_0^T |phi|^2 ds < oo (classes H^2_W of Section 3). The scalar building block is the Ito integral
of a real square-integrable predictable (or progressive) integrand against ONE real Brownian motion
(a component W^j), relative to the standing filtration (F_t) (usual augmentation of the filtration
generated by W, N and F_0), with respect to which W is an (F_t)-Brownian motion.

What a faithful Lean definition must be.
- For an integrand phi : time -> Omega -> R that is predictable/progressive w.r.t. the filtration and
  with E int_0^T phi^2 dt < oo: a random variable (for each t) equal a.s. to the L^2(P)-limit of the
  elementary integrals sum_k xi_k (W_{t_{k+1} ^ t} - W_{t_k ^ t}) along simple adapted approximations,
  i.e. the unique L^2-isometric extension (Ito isometry E|I_t(phi)|^2 = E int_0^t phi^2 ds) of the
  elementary integral.
- Determined only up to P-null sets (a representative of an L^2 class at each t); identities in the
  paper are "a.s. for every t", so a per-t representative is acceptable provided the propositions use
  it only a.s. and pair it with cadlag/continuous versions where they need path properties.
- The integral must be against the given BM W (not another process) and the integrability/measurability
  must be relative to the paper's filtration; the stochastic integral of an integrand that is only
  adapted to a filtration with respect to which W is not a Brownian motion would be a different object.
- Junk value for integrands outside the class (not predictable or not square-integrable): any value
  (e.g. 0) is harmless provided every proposition that uses it requires the integrand to be in the class
  (the paper only integrates elements of H^2_W / progressive square-integrable coefficient processes).
- Upper limit: int_0^t with t in [0,T]; dependence on t should be that of the integral process
  (I_t = I_T(phi 1_{[0,t]}) a.s.).
